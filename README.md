# Wohin jetzt?

Web-App für Freunde, die nicht wissen, was sie machen sollen: Standort + Zeit/Verkehrsmittel + Kategorien → 10 Orte in der Nähe (München). Mit Abstimmung (Handy rumgeben oder per Link).

- Statische Seite, kein Build nötig (Vercel: Framework „Other“, kein Build-Befehl)
- Ortsdaten: OpenStreetMap (Overpass API), Adressen: Nominatim, Karte: Leaflet
- Komplett kostenlos, keine Konten, kein Server
